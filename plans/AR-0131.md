Implement the first real execution controller. Given a Coordinator-bound task revision, project/worktree, registry profile, authority admission result, and scheduler lease, validate every binding and spawn one local fake agent process through the enforceable sandbox. Use argv-only launch, explicit environment, stdin/stdout/stderr pipes, process-group ownership, resource budgets, session identity, and durable spawn/terminal evidence. Admission must fail closed when any lease, registry, authority, sandbox, or revision binding is absent. CI must spawn a deterministic fake process and prove no unadmitted process can start; no external provider is required.
Provider assumption: the selected agent profile is already configured with its provider, credential/key, and model. Runtime must not provision, inspect, copy, or mutate those values.
