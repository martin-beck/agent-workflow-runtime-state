# AR-0081 executable Coordinator state client

Replace the file-backed/reference-only path with a production-shaped client interface while keeping authority in Coordinator. Implement typed reads and CAS writes, auth references, bounded retries, idempotency, correlation, timeout, and ambiguous-outcome recovery. A deterministic in-process Coordinator fake must cover concurrent revisions, stale writes, duplicate writes, transport loss after commit, malformed responses, and unavailable service. Tests must prove no local success is promoted to remote success.
