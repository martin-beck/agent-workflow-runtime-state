Define a machine-checkable transition and temporal model for Agent Workflow Quality (AWQ), Agent Workflow Runtime (AWR), Agent Workflow Coordinator (AWC/Coordinator), and Agent Workflow Guidance (AWG), including the decision interface owned by Agent Workflow UI. Model admission, lease, dispatch, execution, evidence submission, quality result, oracle escalation, guidance decision, user decision, retry, block, recovery, and terminal commit for multiple concurrent jobs. Prove fail-closed invariants: no dispatch without AWC admission and lease; no quality-qualified continuation without AWQ acceptance; no material alternative without AWG decision; no completion without AWC terminal commit; no missing, stale, ambiguous, or LLM-authored authority result may default to approval. A required change or refinement to a user decision, test, or specification must create an AWG decision request and receive a validated decision-interface/UI result before mutation; AWR and autonomous workers cannot alter those artifacts directly. If a worker is blocked and bounded repair workers cannot resolve it, the model must escalate through AWG and the decision interface/UI rather than retrying indefinitely or silently changing scope. Add bounded model checking, exhaustive hostile traces, refinement mappings to runtime events, and tests for control-flow omissions and crossed revisions.
