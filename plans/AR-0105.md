# AR-0105 Deterministic local mock end-to-end workflow

Build an end-to-end deterministic workflow that starts from a newly bootstrapped sample project, admits a task through Coordinator, dispatches a local deterministic mock worker, records normalized execution/evidence events, obtains AWQ evaluation, exercises AWG escalation and a validated UI decision path, and reaches an explicit Coordinator terminal commit. Include success, rejection, blocked, timeout, crash/recovery, stale-result, replay, and unresolved-decision scenarios. Assert exact revision/lease bindings, event ordering, evidence provenance, privacy projection, and final durable state. The fixture must run offline, without LLMs, provider credentials, hosted systems, or nondeterministic sleeps; this is a mock acceptance path and must be labelled as such rather than treated as provider qualification.

## Acceptance evidence

- Versioned contract or implementation artifacts with exact source revision and reproducible local commands.
- Positive and hostile checks for the failure and authority boundaries in scope.
- Offline operation demonstrated; provider/backend access remains optional and absent from mandatory acceptance.
- Limitations and unsupported cases stated explicitly; no readiness claim based only on configuration or unit tests.
