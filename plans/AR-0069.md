# AR-0069 executable runtime kernel and persistence boundary

Build the first executable composition layer over AR-0061 through AR-0066.
Keep policy authorities outside the kernel; runtime code may enforce declared
contracts and emit evidence but may not grant quality, oracle, UI, or merge
authority.

Required slices:

- versioned local state store and append-only event transaction interface;
- exact task/project/worktree/session/revision/lease binding;
- idempotent operation records and recovery bootstrap;
- atomic evidence/accounting coupling and bounded retention;
- temporary/in-memory backend for deterministic tests;
- hostile tests for torn writes, replay, stale revisions, privacy, and restart.

No network, provider process, LLM, or live Coordinator call is permitted in
this AR.
