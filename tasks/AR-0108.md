Threat-model the local runtime, project roots, authority bridges, workers, UI decision path, package updates, and logs. Implement least-privilege execution/isolation controls, path and symlink containment, secure local IPC/authentication where applicable, secret handling, safe temporary files, input/schema validation, resource limits, and fail-closed behavior. Explicitly distinguish supported isolation guarantees from best-effort controls on each platform; never claim a sandbox without enforcement evidence. Test path traversal, symlink races, untrusted worker output, forged/replayed bridge messages, secret leakage, permission failures, resource exhaustion, and crash recovery with deterministic local adversarial fixtures. Providers remain optional and credentials absent in baseline operation.
