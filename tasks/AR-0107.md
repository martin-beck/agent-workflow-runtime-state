Deliver structured local logs, event traces, health/readiness diagnostics, bounded metrics, and CLI status/doctor views covering package/bootstrap, project binding, coordinator and authority bridge health, scheduler/worker lifecycle, evidence flow, and terminal outcomes. Correlate events using opaque project/task/revision identifiers without logging secrets, prompts, private decision content, or raw provider payloads by default. Define retention, rotation, export, and redaction behavior. Diagnostics must distinguish unavailable, unsupported, unknown, rejected, and healthy states and never report readiness from configuration alone. Provide deterministic golden traces, hostile secret-canary/redaction checks, and documentation; observability must function without external telemetry services.
