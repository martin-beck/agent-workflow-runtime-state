Implement the bounded subprocess/session transport used by all provider
adapters. It must enforce framing, output/event budgets, backpressure,
timeouts, interruption, checkpoint/resume handoff, exit classification,
capability negotiation, redaction, and exact task/session/lease binding.

The harness must run deterministic local fake executables and hostile protocol
fixtures only; it must not invoke a real coding agent or external service.
