# AR-0083 local host supervisor and sandbox enforcement

Implement the actual local process boundary, not a structural checker: allowlisted executable, sanitized environment, exact worktree, resource/time budget, process group, cancellation, output cap, cleanup, and lease fence. Use repository-owned helper processes and temp repositories only. Test successful completion, timeout, cancellation, child process loss, output overflow, path escape, environment leakage, stale lease, and unsupported kernel controls; fail closed on every unsupported control.
