# AR-0068 scheduler and contractor local-mock pilot

Run a bounded executable pilot using a deterministic local mock agent service/library at the provider boundary (LiteLLM-style request/response shape is acceptable, but no LiteLLM installation, backend, credential, network, or external LLM is required). Exercise the scheduler, adapter transport, contractor lifecycle, evidence, accounting, observability, retry, interruption, and reconciliation paths across a bounded local cohort.

The pilot must prove the local runtime call path only. It must explicitly report `external_provider: not_performed`, `network: disabled`, `credentials: not_supplied`, and `remote: unverified`; it must never claim support for a real provider or production host. Any malformed mock response, budget overrun, stale binding, replay, interruption, or failed acceptance must fail closed and retain a digest-linked counterexample. A successful local-mock pilot is not live provider qualification.
