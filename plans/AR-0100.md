# AR-0100 Umbrella and runtime registration

Update the umbrella project manifest and runtime project registration metadata so the runtime is discoverable as a first-class product child with its product repository, state repository, ownership, lifecycle, and canonical status/coordination entrypoints. Define the integration boundary: the umbrella routes work and presents status; the runtime owns execution, supervision, isolation, normalized events, and runtime bridges; Coordinator/AWC owns task identity and durable state; AWQ owns quality contracts and evidence; AWG owns oracle guidance/decisions; UI owns human interaction. Validate all referenced repositories and paths, detect duplicate child IDs/paths and broken links, and provide deterministic local positive and hostile checks. Do not modify the child product repository in this task. Registration must not imply provider/backend availability or production readiness.

## Acceptance evidence

- Versioned contract or implementation artifacts with exact source revision and reproducible local commands.
- Positive and hostile checks for the failure and authority boundaries in scope.
- Offline operation demonstrated; provider/backend access remains optional and absent from mandatory acceptance.
- Limitations and unsupported cases stated explicitly; no readiness claim based only on configuration or unit tests.
