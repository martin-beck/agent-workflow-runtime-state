Define and implement versioning, reproducible build inputs, signed/provenance-bearing release artifacts, checksums, supported platform matrix, compatibility declarations, and release qualification for package plus CLI bootstrap. Specify upgrade, rollback, state/schema migration, backup, interrupted-update recovery, and downgrade refusal when unsafe. Validate artifact contents and source revision, install from the built artifact in clean environments, exercise upgrade and recovery from prior supported versions, and verify signatures/checksums independently. Release publication must not depend on a live provider/backend; hosted release infrastructure may distribute artifacts but cannot be required for local build, validation, installation, or mock workflow.
