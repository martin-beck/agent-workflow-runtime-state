Define a machine-checkable transition and temporal model for Agent Workflow Quality (AWQ), Agent Workflow Runtime (AWR), Agent Workflow Coordinator (AWC/Coordinator), and Agent Workflow Guidance (AWG). Model admission, lease, dispatch, execution, evidence submission, quality result, oracle escalation, guidance decision, retry, block, recovery, and terminal commit for multiple concurrent jobs. Prove fail-closed invariants: no dispatch without AWC admission and lease; no quality-qualified continuation without AWQ acceptance; no material alternative without AWG decision; no completion without AWC terminal commit; no missing, stale, ambiguous, or LLM-authored authority result may default to approval. Add bounded model checking, exhaustive hostile traces, refinement mappings to runtime events, and tests for control-flow omissions and crossed revisions.
