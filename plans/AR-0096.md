# AR-0096 production readiness and staged rollout gate

Define a release dossier and machine-checkable gate for security, compatibility, capacity, SLOs, recovery, observability, deployment, support, incident response, rollback, documentation, and residual risk. Run local-mock canary/load/upgrade/rollback acceptance and require all evidence to be revision-bound. Real provider availability, model quality, and remote consumption remain separate observations and are never prerequisites for the runtime AR.
