# AR-0097 autonomous development case-study and improvement loop

Implement a generic case-study schema and exporter over AR-0090, AR-0091, AR-0095, and AR-0096. It must distinguish fully autonomous segments from human-assisted, blocked, retried, or externally resolved segments; preserve exact revisions and evidence digests; and classify observations as outcome, failure, intervention, bottleneck, or improvement proposal.

Use synthetic project histories plus sanitized fixtures supplied by consuming projects. Test concurrent cycles, missing evidence, contradictory terminal states, privacy leakage, cross-project mixing, replay, and proposal approval boundaries. The output is analysis and proposed guidance only: it cannot mutate runtime policy, approve a release, author AWG guidance, or make an application project part of the runtime.
