# AR-0101 Installable runtime package and CLI bootstrap

Specify and implement the runtime distribution artifact, supported installation modes, version/provenance metadata, and stable CLI entrypoint. Bootstrap must detect prerequisites, select/create a user-owned runtime home, initialize configuration and local state safely, verify permissions and compatibility, and produce actionable diagnostics without secrets. Support fresh install, upgrade, repair, and uninstall/rollback semantics; never overwrite unrelated user data. Include deterministic package/build checks, clean-environment installation smoke checks, CLI help/version/doctor checks, and hostile tests for partial installs, corrupt config, path spaces, permissions, and interrupted bootstrap. Network access may be used to obtain a package by the user, but no external service, provider, or backend is required to install or bootstrap.

## Acceptance evidence

- Versioned contract or implementation artifacts with exact source revision and reproducible local commands.
- Positive and hostile checks for the failure and authority boundaries in scope.
- Offline operation demonstrated; provider/backend access remains optional and absent from mandatory acceptance.
- Limitations and unsupported cases stated explicitly; no readiness claim based only on configuration or unit tests.
